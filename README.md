# 威尔逊木头转草 / Wilson Log to Grass

饥荒联机版模组：威尔逊可以在角色专属制作栏里，将 1 个木头转化为 3 个草。配方初始可用，无需技能点或工作站。服务器和所有客户端都需启用模组。

## English

This Don't Starve Together mod adds a Wilson-exclusive recipe to the character crafting tab: turn one log into three cut grass. It is available from the start and requires no skill points or crafting station. The server and all clients must enable the mod.
