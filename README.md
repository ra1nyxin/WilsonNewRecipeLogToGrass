# 威尔逊木头转草 / Wilson Log to Grass

饥荒联机版模组：威尔逊可以在角色专属制作栏里将木头转化为草，默认用 1 个木头换 3 个草。可在模组配置页面分别调整木头和草的数量，每项提供 1 至 5000 的预设选项。配方初始可用，无需技能点或工作站。服务器和所有客户端都需启用模组；多人游戏使用服务器的配置。

## English

This Don't Starve Together mod adds a Wilson-exclusive recipe to the character crafting tab, converting logs to cut grass. The default is one log for three grass; both quantities can be configured independently using preset values from 1 to 5000. It is available from the start and requires no skill points or crafting station. The server and all clients must enable the mod; multiplayer uses the server's configuration.
